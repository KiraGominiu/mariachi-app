⚪ No conectado a Google Calendar
🔑 Configuración de Google Calendar API
Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client IDs
Google Cloud Console → APIs & Services → Credentials → API Keys
📋 Cómo obtener las credenciales — paso a paso
1
Ve a console.cloud.google.com e inicia sesión con tu cuenta Google
2
Crea un proyecto nuevo — clic en "Select a project" → "New Project" → nombre: Mariachi Horarios → Create
3
Activa la API de Calendar — APIs & Services → Library → busca Google Calendar API → Enable
4
Configura la pantalla de consentimiento OAuth — APIs & Services → OAuth consent screen → External → rellena nombre de app y tu email → Save
5
Crea OAuth 2.0 Client ID — Credentials → Create Credentials → OAuth Client ID → tipo: Web application
En "Authorized JavaScript origins" agrega: http://localhost:5500 y http://127.0.0.1:5500
Copia el Client ID y pégalo arriba
6
Crea una API Key — Credentials → Create Credentials → API Key → cópiala y pégala arriba
7
Presiona "Guardar" y luego "Conectar con Google" — aparecerá una ventana de Google para autorizar
⬇ Exportar sin configuración — archivo .ics

Si no quieres configurar la API, descarga el archivo .ics e impórtalo en Google Calendar manualmente.

Google Calendar → ⚙ Configuración → Importar y exportar → Importar → selecciona el archivo .ics
💻 En VS Code (recomendado para laptop)
1
Abre VS Code → File → Open Folder → selecciona la carpeta mariachi-app que descomprimiste del ZIP
2
Instala la extensión Live Server — Extensions (Ctrl+Shift+X) → busca Live Server de Ritwick Dey → Install
3
Clic derecho en index.html → "Open with Live Server" — se abre en Chrome en http://localhost:5500
4
Para instalarla como app: en Chrome, busca el ícono ⊕ en la barra de direcciones → "Instalar Mariachi Estrella Brillante"
📱 En celular Android
1
Comparte el archivo index.html a tu celular (WhatsApp, Drive, cable)
2
Ábrelo con Chrome → menú ⋮ → "Agregar a pantalla de inicio"
3
Confirma → se instala como app nativa con ícono propio
🍎 En iPhone
1
Abre el archivo en Safari (no Chrome en iOS)
2
Toca el botón compartir □↑ → "Agregar a pantalla de inicio" → Agregar
✅ Una vez instalada, funciona sin internet
💾 Las distancias y configuración se guardan en tu dispositivo
🔄 Para actualizar, reemplaza el archivo index.html y recarga
