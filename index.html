🔑 Configuración API

📋 Pasos para obtener credenciales
1
Ve a console.cloud.google.com e inicia sesión
2
Crea proyecto → "New Project" → nombre: Mariachi Horarios
3
Activa Calendar API → APIs & Services → Library → Google Calendar API → Enable
4
OAuth consent screen → External → rellena nombre y email
5
Crea OAuth Client ID → Web Application → agrega en Authorized JavaScript origins:
https://mariachi-app-production.up.railway.app
6
Crea API Key → Credentials → Create Credentials → API Key
7
Pega ambos arriba → Guardar → Conectar con Google
